The Vision

The Purpose of
MXSA.

The primary purpose of Project MXSA is to bridge the gap between advanced artificial intelligence and physical, bionic interaction. MXSA is not just a passive smart assistant; it is a fully localized, autonomous entity.

It perceives its environment, understands natural language, expresses dynamic emotions, and physically manipulates objects using its highly advanced robotic arm and 3-finger triangular gripper.

Designed to run entirely on the edge (Raspberry Pi 4) without relying on cloud APIs, MXSA guarantees privacy, zero-latency reactions, and true autonomy.

🧠

The Brain & Emotional Core

Powered by Qwen2.5-0.5B via Llama.cpp for logical thoughts, with an Affective Emotional Matrix tracking Arousal/Valence for 20+ emotions.

🦾

The Max Shadow Arm

3-DOF robotic arm with a 3-finger triangular gripper. Understands physical sign language natively via voice commands.

👁️

Edge Computer Vision

Hybrid Detection Pipeline (YOLOv5n + MobileNetV2) dynamically scans and sweeps the area to locate trained objects and fetch them.

🗣️

Localized Voice Recognition

Offline NLP using Vosk for lightning-fast speech-to-text and Fuzzy Command Parsing engine mapping casual phrases to robotic states.

System Architecture

Operational Modes.
By Design.

01
🌐

Mode 1: The AI Brain

The live, autonomous operational mode. Watch live telemetry, read real-time LLM thoughts, view the emotional matrix, and override the AI via a WASD D-Pad and live servo sliders through the ultra-premium web UI.

02
🎯

Mode 2: The Training Studio

Use your PC's webcam to capture massive datasets of personal objects. Manage the gallery, train custom models, and instantly deploy new weights directly to the robot's memory banks over the network.

03
⚙️

Infinite Runtime

Built for resilience. Aggressive Python garbage collection, hard-capped JSONL log rotation, and dynamic hardware fallbacks prevent the system from crashing even if a physical wire is suddenly unplugged.

04
🛡️

100% Edge AI

Zero cloud APIs. Everything from computer vision to the Large Language Model runs completely locally on the device, guaranteeing total privacy, unparalleled latency, and no recurring server costs.
